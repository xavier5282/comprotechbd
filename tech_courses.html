What you will learn

A practical path from computer components to confident technical support.

Hardware Fundamentals

Understand CPUs, motherboards, memory, storage, power supplies, and how components work together.

Computer Assembly

Learn how to identify parts, assemble a workstation, install components, and prepare a system for use.

Operating Systems

Explore Windows and Linux installation, drivers, updates, boot processes, and basic system management.

Networking Basics

Understand device connections, internet fundamentals, privacy, security, and common network limitations.

Troubleshooting

Follow a repeatable diagnostic process for hardware, software, connectivity, and workstation issues.

Practical Labs

Apply each concept through guided exercises and finish with a project that demonstrates your new skills.
