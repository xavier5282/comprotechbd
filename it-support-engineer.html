Course curriculum

Learn how to diagnose, restore, and support real IT systems confidently.

01

IT Support Fundamentals

Learn the role of an IT Support Engineer, L1/L2/L3 workflows, troubleshooting methodology, and ticket handling.

  • Diagnose user issues in a proper workflow
  • Document incidents and resolutions
  • Follow real service desk processes
02

Computer Hardware

Understand motherboard, chipset, CPU, RAM, storage, power supply, GPU, and hardware compatibility.

  • Identify motherboard components
  • Understand CPU socket and RAM types
  • Use hardware knowledge in troubleshooting
03

PC Assembly & Preventive Maintenance

Assemble systems, install CPU, RAM, GPU, SSD, PSU, and perform cleaning and health checks.

  • Install and assemble full PCs
  • Diagnose no POST, no display, and overheating
  • Apply preventive maintenance best practices
04

Operating Systems

Install and configure Windows and Linux, understand partitions, services, commands, and basic OS troubleshooting.

  • Install Windows 11 and Linux
  • Use command-line basics
  • Understand system logs and service status
05

Windows Administration

Manage users, groups, services, drivers, Device Manager, event logs, Windows Update, PowerShell, and common Windows problems.

  • Create local accounts and permissions
  • Troubleshoot slow Windows and startup issues
  • Use PowerShell for system checks
06

Linux Fundamentals

Learn Linux file structure, users, permissions, packages, networking, logs, systemctl, and essential administration commands.

  • Configure static IP and SSH
  • Manage services and permissions
  • Analyze logs and system health
07

Networking Fundamentals

Understand LAN/WAN, Ethernet, IPv4/IPv6, subnets, DNS, DHCP, NAT, VLAN, routers, switches, and networking tools.

  • Create IP addressing plans
  • Configure network settings and tests
  • Understand switches, routers, and ports
08

Network Troubleshooting

Work through physical, data link, network, and application-layer issues with practical scenarios.

  • Check cables, NICs, VLANs, subnetting, and DNS
  • Troubleshoot internet and local connectivity
  • Use ping, ipconfig, tracert, nslookup, and Wireshark
09

Active Directory & Windows Server

Build a small-domain environment with DNS, DHCP, users, groups, OUs, computers, and Group Policy.

  • Create domain users and groups
  • Administer a small Windows Server lab
  • Fix AD and shared access issues
10

Storage, Backup & Data Recovery

Understand HDD, SSD, NVMe, RAID, SAN, NAS, backups, restores, and the 3-2-1 backup strategy.

  • Compare RAID levels and performance
  • Create backup jobs and test file restore
  • Recover from common storage faults
11

Printers & Peripheral Devices

Install and troubleshoot USB printers, network printers, scanners, webcams, barcode scanners, UPS, and projector equipment.

  • Fix printer offline and queue issues
  • Resolve driver and spooler problems
  • Manage shared network printer access
12

IT Security

Apply endpoint security, firewalls, patching, MFA, least privilege, password hygiene, and awareness of malware and phishing.

  • Protect endpoints and accounts
  • Use Windows Defender and firewall rules
  • Harden user access and remote access
13

Remote Support & Help Desk

Manage tickets, prioritize incidents, use remote support tools, escalate engineering issues, and maintain service quality.

  • Process incidents from intake to closure
  • Use L1/L2/L3 escalation properly
  • Document solutions and maintain knowledge base entries
14

Virtualization & Cloud Fundamentals

Understand virtual machines, hypervisors, snapshots, templates, and cloud basics such as IaaS, PaaS, SaaS, and cloud backup.

  • Deploy VMs in virtualized labs
  • Understand VM resource allocation
  • Recognize cloud service models
15

IT Documentation & Asset Management

Build proper asset records, network diagrams, inventory lists, troubleshooting reports, and change documentation.

  • Track hardware and software inventory
  • Create troubleshooting and incident reports
  • Document network and system changes clearly
16

Advanced Troubleshooting Scenarios

Practice in realistic support environments: no boot, slow Windows, internet outages, shared folder access issues, printer problems, and AD login failures.

  • Identify root cause rather than guessing
  • Verify fixes and document them
  • Handle escalations with structured troubleshooting
17

Final Practical Project

Set up and troubleshoot a complete small business IT environment with Windows Server, AD, DNS, DHCP, clients, shared folders, file permissions, printer, backup, and firewall.

  • Configure a small office IT infrastructure
  • Resolve intentionally introduced faults
  • Deliver a final practical assessment
